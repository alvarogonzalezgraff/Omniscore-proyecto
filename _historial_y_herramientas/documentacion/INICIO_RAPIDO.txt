╔══════════════════════════════════════════════════════════════════════════════╗
║                    🚀 INICIO RÁPIDO - Selector de Jornadas                   ║
╚══════════════════════════════════════════════════════════════════════════════╝

┌──────────────────────────────────────────────────────────────────────────────┐
│  PASO 1: Iniciar el Servidor API                                            │
└──────────────────────────────────────────────────────────────────────────────┘

  Abre una terminal en: c:\Users\pc\Desktop\proyecto
  
  Ejecuta:
  
    python -m api.main
  
  ✅ Deberías ver:
     INFO:     Uvicorn running on http://0.0.0.0:8001 (Press CTRL+C to quit)


┌──────────────────────────────────────────────────────────────────────────────┐
│  PASO 2: Abrir en el Navegador                                              │
└──────────────────────────────────────────────────────────────────────────────┘

  Abre tu navegador favorito y ve a:
  
    http://localhost:8001/laliga
  
  ✅ La página debería cargar con la clasificación de LaLiga


┌──────────────────────────────────────────────────────────────────────────────┐
│  PASO 3: Ir a la Pestaña de Resultados                                      │
└──────────────────────────────────────────────────────────────────────────────┘

  Haz clic en el botón:
  
    ⚽ Resultados
  
  ✅ Deberías ver el selector de jornadas con 38 botones


┌──────────────────────────────────────────────────────────────────────────────┐
│  PASO 4: Probar el Selector                                                 │
└──────────────────────────────────────────────────────────────────────────────┘

  Prueba estas acciones:
  
  1. Haz clic en "J5"
     → Solo se muestran los partidos de la Jornada 5
  
  2. Haz clic en "J1"
     → Solo se muestran los partidos de la Jornada 1
  
  3. Haz clic en "Todas las Jornadas"
     → Se muestran todas las jornadas nuevamente
  
  ✅ El filtrado debería ser instantáneo


╔══════════════════════════════════════════════════════════════════════════════╗
║                              ⚠️ SOLUCIÓN DE PROBLEMAS                        ║
╚══════════════════════════════════════════════════════════════════════════════╝

┌──────────────────────────────────────────────────────────────────────────────┐
│  PROBLEMA: "No se pudo conectar con la API"                                 │
└──────────────────────────────────────────────────────────────────────────────┘

  SOLUCIÓN:
  1. Verifica que el servidor API esté corriendo
  2. Revisa que esté en el puerto 8001
  3. Intenta: python -m api.main


┌──────────────────────────────────────────────────────────────────────────────┐
│  PROBLEMA: "Los botones no aparecen"                                        │
└──────────────────────────────────────────────────────────────────────────────┘

  SOLUCIÓN:
  1. Abre la consola del navegador (F12)
  2. Busca errores en JavaScript
  3. Refresca la página (Ctrl+F5)


┌──────────────────────────────────────────────────────────────────────────────┐
│  PROBLEMA: "Al hacer clic no filtra"                                        │
└──────────────────────────────────────────────────────────────────────────────┘

  SOLUCIÓN:
  1. Verifica que la API esté respondiendo
  2. Abre la consola del navegador (F12)
  3. Verifica que no haya errores de JavaScript
